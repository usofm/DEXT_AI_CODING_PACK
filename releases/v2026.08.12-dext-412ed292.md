## Important Rules Captured

- use `{id}` route parameters, not `:id`
- use current controller attributes and source syntax
- prefer typed endpoint/service injection over manual service lookup
- ORM query results use `IList<T>`
- repository-wide guidance prefers `[MaxLength(N)]` over stale `[StringLength]`
- exact financial precision uses `TBcd` / `FmtBcdType` when required
- detached ORM entities must be attached/updated correctly before save
- Web DbContexts should use pooling where applicable
- `Mock<T>` is a record and must not be freed
- FastPath is selective, not the default architecture
- prefer scoped/RAII pool leases such as `AcquireScoped` where available
- distinguish SSE, WebSocket, Hubs and Event Bus by semantics
- current Dext source outranks example README text
