## Why r3 exists

A practical Golden Starter exercise exposed an abstraction-overreach failure mode: an agent could follow general Clean Architecture habits and generate a manual Repository + FireDAC/UniDAC query layer even when native Dext Entity ORM already provided the intended persistence model.

That output was technically plausible Delphi, but it did not sufficiently resemble or exploit Dext's own architecture.

`r3` closes that gap.

## Dext-native first

Agents must now verify native Dext mechanisms before introducing framework-like wrappers.

For normal CRUD, the default persistence path is:

```text
Endpoint / Controller
  -> Application Service / Manager
      -> scoped TDbContext
          -> IDbSet<TEntity>
              -> Dext Entity ORM
```

A manual stack such as:

```text
IRepository
  -> TFDQuery / TUniQuery
      -> ConnectionFactory
```

is no longer a default recommendation. It requires a concrete reason such as specialized provider SQL, stored-procedure contracts, unusual bulk/import behavior, external persistence, or another meaningful integration/domain boundary.

## Native composition guidance added

The Pack now explicitly guides agents toward current Dext facilities including:

- `IStartup` / `App.UseStartup(...)`
- `TDbContext` / `IDbSet<T>`
- `AddDbContext<TContext>`
- `UsePostgreSQL`, `UseFirebird`, `UseConnectionDef`, and other native provider helpers
- `.WithPooling(True)` for appropriate Web workloads
- Smart Properties / `Prototype.Entity<T>`
- Specifications
- `IList<T>` ORM collections
- `.Update(Entity)` before `SaveChanges` where required
- `BcdType` / `FmtBcdType` + `[Precision(P,S)]` for exact decimals

## Native authentication guidance added

Agents should prefer Dext authentication primitives before adding custom JWT wrappers:

- `IJwtTokenHandler`
- `TJwtTokenHandler`
- `TClaimsBuilder`
- `UseJwtAuthentication`
- `RequireAuthorization`

## Practical evidence

This correction was derived from a three-way audit of:

1. official Dext source/docs/examples at the compatibility SHA;
2. `DEXT_AI_CODING_PACK` guidance;
3. the practical `DEXT_ENTERPRISE_STARTER` implementation.

The starter was then refactored from manual provider CRUD to native Dext Entity patterns.
