# DEXT AI Coding Pack — v2026.08.12-r2-dext-412ed292

Pack-only hardening revision of the first canonical DEXT AI Coding Pack release.

## Compatibility Anchor

Upstream Dext is unchanged from the canonical release:

```text
cesarliws/dext@412ed29207d2d1dc5d4a259a7739a615aed0c626
```

This revision changes Pack maintenance/release infrastructure, not the audited Dext compatibility anchor.

## Added in r2

### Executable self-validation

- `tools/validate_pack.py`
- dependency-free structural checks
- version consistency checks
- upstream SHA consistency checks
- full artifact part-count checks
- skill/prompt presence checks
- release-note/version matching
- critical agent behavior guard checks

### GitHub Actions CI

- `.github/workflows/quality-gate.yml`
  - runs on push/PR/manual dispatch
  - executes the Pack validator
  - checks Markdown artifacts are non-empty
  - checks current release notes exist

### Upstream drift detection

- `.github/workflows/upstream-drift.yml`
  - scheduled daily
  - compares audited Dext SHA with `cesarliws/dext/main`
  - opens or updates a GitHub issue when drift is detected
  - fails visibly until the Pack is refreshed

### Guarded release publication

- `.github/workflows/publish-release.yml`
  - runs only after a successful Pack Quality Gate on `main`
  - re-runs the validator
  - refuses to publish if upstream Dext moved
  - verifies version/manifest/snapshot/changelog agreement
  - creates an immutable version tag only if missing
  - creates the matching GitHub Release only if missing
  - is idempotent for existing tags/releases

### Contribution hygiene

- `CONTRIBUTING.md`
- `.github/PULL_REQUEST_TEMPLATE.md`
- explicit source-precedence and impact-scoping requirements
- mandatory validation/evidence checklist for agent-facing changes

## Release Safety

Publication is allowed only when:

```text
Pack Quality Gate = PASS
AND current Dext HEAD = audited SHA
AND manifest/snapshot/changelog/release notes agree
```

If upstream Dext moves, the release workflow stops and the refresh workflow must run first.
